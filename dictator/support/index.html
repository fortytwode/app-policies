Dictator Support

For help with Dictator, email hi@rocketshiphq.com. Include your iPhone model, iOS version, and what you were doing when the issue occurred. Please do not email dictation text, API keys, or other sensitive content.

Set up the keyboard

Open iOS Settings → General → Keyboard → Keyboards → Add New Keyboard and choose Dictator. Tap Dictator in the keyboard list and enable Allow Full Access. Full Access lets the keyboard communicate with the Dictator app through its shared container; it does not mean Dictator collects what you type.

Start dictating

Start a session in Dictator, switch back to your text field using the iOS Back control, then use the Dictator keyboard microphone button. The session keeps the microphone available in the background and iOS shows its microphone indicator. End the session in Dictator or let it expire based on your session setting.

Anthropic permission

Claude cleanup requires an Anthropic API key and the separate permission in Settings. The permission disclosure describes the transcript, nearby cursor text, and spelling hints sent to Anthropic. Turn the permission off to stop future Claude requests, or remove the key in Settings. See the Dictator Privacy Policy.

History and model downloads

Use the History screen to delete individual items or clear all saved dictation history. Settings lets you change history retention and delete a downloaded Whisper model.
